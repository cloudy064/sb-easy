## 实施约束

- `c/`、`windows/` 保持 C11；不向历史 C++/Rust 实现新增功能。
- 保留工作区既有修改和下载产物；测试使用隔离数据与临时端口，不操作生产 Agent/数据库/路由。
- 现有基线：C Release 与 ASan/UBSan 各 18/18 通过；前端类型检查/构建通过。这是实施前基线，不是新增功能验收。
- 生产签名凭据、Apple 构建/签名环境和真实设备验收必须有实际证据，不能由模拟测试代替。

## 新发现

- 中心 `refresh_interval` 原来只有存储/UI，C 服务没有周期订阅刷新线程。F04 同时覆盖中心后台调度，不仅补 Windows 客户端。
