# 历史统计、告警与 Prometheus

管理员在“统计与告警”查看设备版本、最近状态、最近成功应用的配置及失败原因。
设备详情中的“历史统计”对具有该设备读取权限的账号开放；跨设备总览、告警确认、
保留设置及抓取令牌管理仅对管理员开放。

## 采样与保留

Agent 遥测和中心自管核心的 Clash API 计数按**中心接收时间**写入 SQLite 的一分钟桶。
每桶记录样本数、上传/下载平均速率、连接峰值、累计计数差和计数器重置次数。
首次计数作为基线，不把启动前流量算入当前分钟；计数下降时从新计数开始累计。
没有上报的区间保持缺口，不补零。重启、未上报的末尾流量及无法识别的计数器变化
可能造成统计误差，因此这些数据不用于计费。不会把连接地址、域名、日志或凭据写入
历史表。自管核心的速率由连续的总量样本估算。

默认保留 30 天，可设为 1–365 天。每 30 秒执行告警评估和保留清理，删除过期采样及
已结束事件；活动事件保留到结束。历史接口最多返回 2000 个聚合桶，支持 60、300、
3600、86400 秒粒度。JSON 配置导出不包含这些运行记录；完整 SQLite 备份包含历史。

## 告警语义

| 事件 | 条件 |
| --- | --- |
| 设备未上报 | 启用的远端设备超过阈值没有状态上报，默认 180 秒；配置轮询不能代替状态上报 |
| 配置未应用 | 已发送的新配置摘要与最后成功上报的摘要不一致超过阈值，默认 300 秒；重复轮询不重置计时 |
| 配置失败 | 设备最近状态明确携带错误；失败上报不会覆盖最后成功配置摘要 |
| 节点不可达 | 最近一小时内的节点探测明确失败 |
| 节点响应慢 | 最近一小时的有效探测达到阈值，默认 5000 毫秒 |
| 节点探测数据过期 | 曾经探测过的启用节点超过一小时没有新结果；过期不被视为恢复健康 |

节点结果来自已有的中心/Agent 主动探测；运维线程不额外访问所有订阅节点。
一个资源的同类问题只有一个活动事件。确认是已读标记，不会抑制恢复判断。
条件消失时结束事件；再次出现时产生新 ID。禁用设备/节点会结束对应活动事件。
若设备在取到新配置前已离线，先由离线事件反映，而不能声称它已接收到该配置。

## Prometheus

在“统计与告警”创建只读抓取令牌，保存到 Prometheus 主机的私有文件中。
明文令牌仅创建/轮换时返回，中心只保存 SHA-256 摘要；轮换和撤销立即使旧令牌失效。
该令牌不能登录面板、操作设备或作为 Agent 凭据。通过 HTTPS 抓取：

```yaml
scrape_configs:
  - job_name: sb-easy
    scheme: https
    metrics_path: /api/metrics
    authorization:
      type: Bearer
      credentials_file: /etc/prometheus/sb-easy-token
    static_configs:
      - targets: ['panel.example.com']
```

指标只使用设备/资源 ID 及固定事件类型作为标签，不包含节点密码、域名、配置正文或
连接地址。`sb_easy_traffic_sample_timestamp_seconds` 标明遥测新鲜度，速率使用最近
采样分钟的均值；离线后不把旧速率解释为当前速率。可通过 Prometheus 告警规则把
`sb_easy_alert_active` 接入自己的 Alertmanager；应用不会擅自发送外部通知。

## 验证

`observability_test` 覆盖真实 HTTP 权限/令牌隔离、撤销、计数基线和重置、缺口、保留、
配置失败保留成功摘要、事件去重/确认/恢复/复发、实际后台线程和数据库重开后的记录。
`scripts/test-https-deployment.py` 在临时端口验证证书、登录 Cookie、重定向及 WebSocket。
