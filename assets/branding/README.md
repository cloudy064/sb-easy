# sb-easy brand mark

The mark combines two interlocking network routes into an abstract `S`. The
center gap represents a rule choosing between direct and proxied traffic.

- Primary mark: `sb-easy-mark-v2.svg` (transparent background)
- Raster export: `sb-easy-mark-v2.png` (1024 × 1024, transparent background)
- Route A: `#43D7A3`
- Route B: `#55BFEF`
- Recommended dark tile: `#0B1118`

Keep the two route colors and preserve clear space around the mark. For tiny
or system-tinted icons, use the same two shapes in a single color.
