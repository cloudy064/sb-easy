sb-easy Windows 0.5.0 流量统计与日志预览

新增
- 流量统计：按 Windows 进程文件名、可注册域名汇总。
- 点击应用或域名进入 host 明细，再点击 host 查看各出站的上传、下载和最近访问。
- 域名按公共后缀和私有后缀归并，IP 保持独立。
- 搜索、按总量/上传/下载/最近访问排序、暂停刷新、确认清空。
- 后台服务每 2 秒采集，关闭 GUI 后继续；每 30 秒及正常停止时保存到受保护的 DPAPI 存储。
- 运行日志：最近 200 行脱敏内核/服务日志，可按来源、级别和关键词筛选。
- EXE、任务栏、托盘、MSI 和快捷方式使用 sb-easy 图标。

验证建议
1. 使用不同应用访问不同网站，打开“流量统计”，检查应用和域名分组。
2. 点击分组，再点击 host，检查出站记录；company 的内网访问仍应走中心下发的 WireGuard。
3. 关闭 GUI 后继续产生流量，再打开 GUI 查看累计；正常停止、重新启动服务后检查历史保留。
4. 在下载过程中清空统计，后续只应累计清空后的流量。
5. 在“运行日志”搜索域名，切换来源和级别，暂停/继续刷新。
6. 如发生问题，从托盘导出完整离线诊断包。

统计口径和限制
- 当前独立 sing-box 的 Clash API 只提供活动连接快照，不提供所有连接结束事件。
- 内核累计总流量与应用/host 归属流量分开显示。采样间结束的短连接及未采到的末尾流量无法完整归属。
- 进程文件名相同的应用实例合并；没有进程信息的连接显示“未知应用”。
- 最多保存 512 个应用/host/出站/规则组合；每次内核运行最多保留 20,000 个连接检查点。
- 达到容量会提示；内核总流量继续累计。清空释放明细及已结束连接检查点。
- 异常断电或强制结束服务可能丢失最后 30 秒未保存数据；轮询期间可能存在统计延迟。
- 界面日志是本次服务启动后的最近 200 行。完整历史在离线诊断包中，日志磁盘轮换约 16 MB。
- 安卓功能差异详见 windows/ANDROID-PARITY.md；本版不宣称所有安卓功能均已对齐。
