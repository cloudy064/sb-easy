sb-easy Windows 0.4.3 测试说明

已定位：服务器 GPT 分组的 Tokyo 2 节点 TCP 连接超时，导致 Codex 域名 DNS 和 HTTPS 失败。
本版新增“路由规则 → GPT / Codex 出口 → 改用默认代理”，同时调整流量和 DNS。
设置仅保存在本机，重启和同步后仍保留；可恢复服务器设置。切换前须断开连接。

1. 使用 MSI 升级，保留设备注册；或使用 portable ZIP。
2. 在路由规则页确认 GPT / Codex 为“使用默认代理（本机设置）”。
3. 退出 Clash，启动 sb-easy 连接，测试 Codex 新对话及持续响应。
4. 无论成功或失败，托盘菜单“导出诊断包（离线）”可导出桌面 ZIP。
5. 如果不通，断开 sb-easy 后恢复 Clash。日志包含域名、节点和网络状态，不含原始配置和注册密钥。

默认出口已做隔离网络探测；未登录 HTTP 响应只能证明传输连通，Codex 登录会话仍需实际复测。
